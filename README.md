## Usage
1. **Сборка программы:**
   ```bash
   make
   ```

2. **Запуск программы:**
   ```bash
   ./bin/program
   ```
   или
   
   ```bash
   make run
   ```

3. **Очистка собранных файлов:**
   ```bash
   make clean
   ```
## Additional Notes

### Компоненты программы
- **Интерфейс** (`include/`) — заголовочные файлы с объявлением структур и функций
- **Сервер** (`src/`) — реализация функций для работы с файлами
- **Клиент** (`src/main.c`) — пользовательский интерфейс и меню
